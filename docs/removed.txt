CARACTERISTICAS QUITADAS DEL LENGUAJE
=====================================

- const (tipos, declaraciones, parametros, for-init; flag is_const)
- Operadores de asignacion compuestos bitwise/modulo: %=, &=, |=
- Operador unario bitwise NOT: ~
- static_cast
- for range-based (for (T x : v)) y el nodo ForRangeStmt
- Notacion cientifica en literales numericos (1e-5)
- Valores default en parametros (Param ... = Expr)
- Capturas de lambda ([=], [&], [x, &y]); solo se permiten lambdas sin capturas []
- new Type(args); solo queda new Type y new Type[n]
